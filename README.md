# PyFTIR

PyFTIR is a Python library for preprocessing Fourier Transform Infrared (FTIR) spectra.

The project aims to provide a modular and reproducible framework for:
- Spectral region handling
- Baseline correction
- Scatter correction
- Smoothing and derivatives
- Intensity normalization
- Configurable preprocessing pipelines

## Status

🚧 Under construction.

The library is in early development and the API may change.

## Installation (development mode)

```bash
pip install -e .
```
